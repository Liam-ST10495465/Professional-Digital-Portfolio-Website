About Me

01

Why Information Technology

I chose to study Information Technology because I've always been interested in how the software we use every day is actually put together. The first time I wrote a small Java program that solved a problem I'd set for myself, I was hooked on the process of thinking through a task logically, then watching it run correctly on the screen. That mix of problem-solving and instant feedback is what keeps me interested in the field.

02

Career goals

In the next year or two, I'm aiming to secure an internship or entry-level developer role where I can apply my Java and web development skills on real projects and learn from more experienced developers. Longer term, I'd like to grow into a well-rounded software developer, comfortable across both back-end logic and front-end interfaces, and eventually take on more design and architecture responsibility within a development team.

03

What interests me in the industry

I'm mainly interested in software development, with a particular pull toward backend logic and problem-solving in Java, alongside building clean, usable interfaces with HTML and CSS. I like that IT professional practice isn't just about writing code that works. It's also about writing code that's readable, well-documented, and maintainable by other people on a team.
