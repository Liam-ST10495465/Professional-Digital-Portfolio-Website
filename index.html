Hi, I'm Liam Marais.

I'm an aspiring software developer currently studying Information Technology in Durban. My focus so far has been on building a solid foundation in Java for backend logic and HTML/CSS for structuring and styling the web. I enjoy the process of breaking a problem down into small, testable pieces and watching a working program come together from them. I'm still early in my journey, but I'm committed to writing clean, well-organised code and learning the professional habits, such as version control, documentation, and clear communication, that go along with good software development. My goal is to grow this portfolio into a real record of that progress as I move toward an internship and, eventually, a junior developer role.
